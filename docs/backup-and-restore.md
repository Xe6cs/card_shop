## طرق الاستعادة

لا تمس الطرق التالية المشروع الحالي، فكلها تُنشئ مجلداً جديداً.

```bash
# من GitHub
git clone --branch v1.0-static-site https://github.com/Xe6cs/card_shop.git card_shop_restored

# من ملف bundle دون إنترنت
git clone card-shop.bundle card_shop_restored
```

أو انسخ مجلد `snapshot` إلى مكان جديد.

إرجاع الموقع الرسمي (`main`) إلى نسخة سابقة لا يتم إلا بموافقة صاحب المشروع.
